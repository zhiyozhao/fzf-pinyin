# 搜索语法

在选择界面中直接输入表里的查询；在 shell 命令中用引号包住查询，防止空格、`|` 和 `$` 被 shell 解释。

这些语法约束的是原文，不是一条看不见的拼音字符串。拼音缩写和末字未完成的写法仍然有效，例如 `^beiji$` 能匹配“北京”。

## 常用查询

下表按默认选项说明。

| 查询 | 用途 | 会匹配 | 不会匹配 |
|---|---|---|---|
| `bj` | 按顺序找，可跳字 | 北京、北小京 | 上海 |
| `'bj` | 找连续文字 | 北京、北京市 | 北小京 |
| `^bj` | 从开头连续匹配 | 北京、北京市 | 去北京、北小京 |
| `bj$` | 连续匹配到结尾 | 北京、去北京 | 北京市、北小京 |
| `^bj$` | 覆盖整行 | 北京 | 去北京、北京市 |
| `'bj'` | 两侧有空白或标点等分隔 | 北京、北京/文件 | 去北京、北京市、北京Server |
| `bj dx` | 两个条件都满足，顺序不限 | 北京大学、大学北京 | 北京小学 |
| `^bj \| ^sh` | 任一条件满足 | 北京、上海 | 南京 |
| `!bj` | 排除连续命中 | 北小京、上海 | 北京、北京市 |
| `!'bj` | 排除包含跳字的命中 | 上海 | 北京、北小京 |
| `!^bj` | 排除开头命中 | 去北京、上海 | 北京、北京市 |
| `!bj$` | 排除结尾命中 | 北京市、上海 | 北京、去北京 |
| `!^bj$` | 只排除整行命中 | 北京市、去北京 | 北京 |

`^bj$` 默认忽略两端空白。`'bj'` 不做中文分词：它不把“北京市”拆成“北京”和“市”。

空格连接的是条件，不是拼音音节；需要同一段连续拼音时不要用空格分隔。`|` 两侧要留空格。组合查询 `^bj | ^sh dx$` 表示“以北京或上海开头，并以大学结尾”；不支持括号表达式。

```sh
printf '北京大学\n上海大学\n北京小学\n' | fzfp --filter='^bj | ^sh dx$'
# 北京大学
# 上海大学
```

## 只搜索某个字段

字段按原文划分。下面只搜索冒号后的城市名，输出仍保留整行：

```sh
printf '01:北京\n02:上海\n' |
  fzfp --delimiter=: --nth=2 --filter='^bj$'
# 01:北京
```

锚点相对于选定的搜索范围。`--nth=1,2` 分别搜索两个范围，不能把第一列的“北”和第二列的“京”拼成一次 `bj` 命中；`--nth=1..2` 则把它们作为一个连续范围搜索。

## 容易误解的选项

| 选项 | 行为 |
|---|---|
| `--exact` | 普通查询要求原文字相邻，仍支持拼音；此时前置单引号反而切回允许跳字 |
| `-i` / `+i` | 忽略 / 区分原文英文字母的大小写；拼音始终不分大小写 |
| `--literal` | 关闭拉丁字母的重音归一化，不会关闭拼音 |
| `+x` | 关闭查询语法，单引号、空格等按普通字符处理；拼音仍启用 |
| `--algo=v1` | 选择字面匹配算法；拼音匹配不切换到另一种算法 |
| `--scheme`、`--tiebreak` | 调整排序；长度和位置按原文计算 |

全部命令行选项可用 `fzfp --help` 查看。Homebrew 安装还提供 `man fzfp`。

# 拼音指南

`fzfp` 同时搜索原文字和拼音，输出仍是原行。下面的例子用于判断“这样输入能不能找到”，不表示只会匹配这一种文字；例如 `bj` 也可能找到“背景”。

## 每个字可以换一种写法

| 原文 | 可输入 | 说明 |
|---|---|---|
| 中国 | `zhongguo`、`zg`、`zhg`、`zguo`、`zhongg` | 每字可用全拼、首字母或声母，包括 zh / ch / sh |
| 北京 | `北jing`、`bei京` | 可以混用原字和拼音 |
| 旅游 | `lvyou`、`lüyou` | ü 也可以写成 v |
| 方案 | `fan` | “方”用 f，“案”用 an |
| 音乐 | `inyue` | 零声母字也接受韵母写法，“音”的 yin 可写成 in |

最后两种属于额外接受的写法，照常输入 `fangan`、`yinyue` 也可以。

## 最后一个字可以没打完

`beiji` 能匹配“北京”，也能匹配“北京市”：这里的“最后”是查询停下来的那个字，不要求它是整行的最后一个字。

但不能在中间的字随意截断，也不能从一个音节中间开始：

| 查询 | 原文 | 是否匹配 | 原因 |
|---|---|---|---|
| `zhonggu` | 中国 | 是 | 最后的 gu 是 guo 的前缀 |
| `zhoguo` | 中国 | 否 | 中间的 zho 不是完整拼音或合法缩写 |
| `hong` | 中 | 否 | 不能从 zhong 的中间开始 |

## 找到更多，或限制为连续文字

默认搜索允许跳过原文字。例如 `beijing` 可以找到“北京”，也可以找到“北京路”或“北小京”。如果结果太宽，先尝试连续搜索：

```sh
printf '北京\n北小京\n北京市\n' | fzfp --filter="'beijing"
# 北京
# 北京市
```

行首、行尾、整行和排除条件见[搜索语法](syntax.md)。拼音缩写和末字前缀在这些语法中仍然有效。

## 多音字、繁体字和大小写

每个字接受字典中的全部读音，不根据词组选择读音。“重庆”可用 `chongqing` 或 `zhongqing`，“银行”可用 `yinhang` 或 `yinxing`。因此姓名、地名的其他读音可能被找到，也可能出现不符合上下文的结果。

字典覆盖的繁体字也可搜索，例如 `taiwan` 匹配“臺灣”。字典外的字仍可输入原字。程序不识别文本语言；日文等文本里的同形汉字也可能按普通话拼音被找到。

拼音不分大小写，`BJ` 和 `bj` 都能找到“北京”。实际的英文字母仍遵守 fzf 的大小写设置：默认情况下，`BJServer` 匹配“北京Server”，不匹配“北京server”；加 `-i` 后两者都匹配。

## 不支持的输入

不支持带声调拼音、数字声调、双拼、方言模糊音或拼写纠错。`bei3jing1` 不能匹配“北京”，英文 `Beijing` 可以作为拼音，但英文含义 `capital` 不会因此匹配“北京”。

结果排序会考虑输入、原文位置和间隔，连续结果不保证永远排在最前面。需要保证连续时使用单引号，需要特定原字时直接输入汉字。开发者可参阅[匹配设计](design.md)。
